# Trainer-MMS2
百货商场物语2修改器，大肥鱼完全创造

百货商场物语2 修改器  ·  使用说明
========================================

一、这是什么
----------------------------------------
针对 Steam 版《百货商场物语2》(Mega Mall Story 2 / KairoGames.exe) 的
实时内存修改器，可以查看并修改三项资源：

    金钱 (G)      ——  对应游戏里的金币
    心币          ——  粉红心形图标那个
    P币           ——  金色圆环图标那个

改完立刻生效，不用重启游戏；之后再让游戏正常存档，数值就会写进存档里。

二、怎么用
----------------------------------------
1. 先启动游戏，读取一个存档，进到商场主画面（顶部能看到金钱/心/P 三个数字）。
   注意：停在标题画面时修改器会提示“还没读取存档”。
2. 双击「百货商场物语2修改器.exe」。
3. 程序会自动找到游戏并显示当前三项数值（首次定位要扫描内存，约 1~3 秒）。
4. 想改成多少：在右侧输入框里输入数字 → 点「设为」。
   也可以直接点「拉满」：金钱 999,999,999 / 心币 9,999 / P币 999,999。
5. 回到游戏看一眼，数字已经变了。建议改完后在游戏里正常存档一次。

如果显示「未连接」：确认游戏在跑，然后点右上角「重新定位」。
游戏关掉重开过之后，也要点一次「重新定位」。

三、注意事项
----------------------------------------
* 需要 .NET 8 桌面运行时。
  换电脑时报错就让系统装一下 “.NET Desktop Runtime 8.0”。
* 程序会读写游戏进程内存，部分杀毒软件可能弹窗/误报，允许即可。
* 只建议在单机模式下玩。数值别设得过于夸张（金钱上限 999,999,999,999），
  免得游戏后续算钱溢出。
* 游戏一旦更新（Steam 自动更新），程序内置的偏移可能失效，
  那时会提示“找不到 AppData 类型名”，需要重新适配。
* 修改前建议备份存档。我已经把改动前的存档备份放在「存档备份」文件夹里，
  要还原就把它覆盖回去（注意：会丢掉这之后的所有进度）。
